# Documentation Structure

This folder contains all organized documentation for the Sígale project.

## Directory Overview

```
docs/
├── architecture/       # System architecture and project overview
├── design/            # UI/UX design, style guides, and visual specifications
├── features/          # Feature-specific documentation
├── guides/            # Implementation guides and platform compatibility
└── implementation/    # Development stage documentation (completed phases)
```

## Archived Materials

Historical files and mockups have been moved to `/archive`:

```
archive/
├── mockups/      # Design mockups, SVG templates, logos, fonts
├── temp/         # Temporary files and test artifacts
└── old-docs/     # Superseded documentation (oldCLAUDE.md, prompts.txt)
```

## Navigation Tips

- For **system architecture**: Start with `architecture/PROJECT_OVERVIEW.md`
- For **design decisions**: Check `design/STYLE_GUIDE.md`
- For **platform-specific issues**: See `guides/` folder
- For **historical context**: Review `implementation/` stage documents
- For **archived assets**: Browse `/archive/mockups/`

## Document Naming Conventions

- **UPPERCASE.md** - Major reference documents
- **lowercase-with-hyphens.md** - Specific guides and focused topics
- **stage#-name.md** - Sequential implementation phases
